# 검색 플레이북

Codex가 매 실행 2단계(웹 검색) 전에 읽고, 6단계(회고)에서 고치는 문서다. 실행할수록 더 잘 찾도록 근거가 있는 것만 고친다.
규칙: 이 문서는 12,000자를 넘지 않는다. 섹션 제목은 바꾸지 않는다. 시크릿과 개인정보를 쓰지 않는다. `## 판단 기준`의 고정 규칙은 지우지 않는다.

## 검색어

카테고리별로 실제로 쓸 검색어. 회고에서 성과가 없던 검색어는 빼고, 잘 잡히던 검색어는 위로 올린다.

- points: `카드사 포인트 적립 이벤트 이번 달`
- points: `페이 출석 체크 이벤트`
- points: `캐시백 이벤트 마감`

## 우선 출처

먼저 볼 사이트와 게시판. 잡힌 딜이 많고 정보(기한·조건)가 정확했던 곳을 위에 둔다.

- 뽐뿌 쿠폰게시판, 이벤트 관련 핫딜 게시판
- 카드사·간편결제 공식 이벤트 페이지 (기한과 조건이 정확하다)

## 피할 출처·패턴

결과가 부정확했거나 사용자가 **무시**한 출처·제목 패턴. 근거(날짜, 이유)를 같이 적는다.

- (아직 없음)

## 판단 기준

고정 규칙 (지우지 않는다):
- 기한이 이미 지났거나 config `min_days_left`보다 가까운 이벤트는 후보에 넣지 않는다. 기한은 페이지에 적힌 것만 쓴다.
- 값을 모르면 `null`. 지어내지 않는다.
- 응모 조건, 대상 카드, 선착순 여부가 있으면 `summary`에 적는다.
